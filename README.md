## 🚀 Featured Projects / 精选项目

Here are some of my recent and most technically challenging projects. <br/>
以下是我近期最具技术挑战和代表性的项目。

### 💖 [Couple-Wish](https://github.com/code4lains/Couple-Wish)
> **A cross-platform interactive platform designed for couples.** / **一款为情侣设计的跨平台互动系统。**
- **Architecture / 架构设计**: Actively maintained across three distinct architectural branches: / 针对不同部署场景维护了三个独立的分支架构：
  - **`main`**: Traditional server-client architecture using Node.js, Express, and MySQL. / 基于 Node.js + Express + MySQL 的传统服务端架构。
  - **`desktop`**: Packaged desktop application utilizing SQLite for local data storage. / 结合 SQLite 实现本地数据存储的桌面端打包分支。
  - **`serverless`**: Fully serverless deployment using Supabase and Cloudflare Pages. / 基于 Supabase + Cloudflare Pages 的纯 Serverless 部署分支。
- **Highlights / 亮点**: Built with modern React 19 and Tailwind CSS. Includes user pairing, interactive wish lists, a multimedia memory wall, condition-based secret messages, and secure encrypted data backups. / 前端基于最新的 React 19 构建，实现了情侣配对、互动心愿单、多媒体回忆墙、条件触发的私密留言以及安全的数据加密备份功能。

### 📡 [Local-Dialog](https://github.com/code4lains/Local-Dialog)
> **A P2P LAN large file transfer & instant messaging assistant for Web & Desktop.** / **基于 WebRTC 的跨平台局域网 P2P 大文件切片传输与即时通信助手。**
- **Stack / 技术栈**: React 19, TypeScript, Material-UI, WebRTC (PeerJS), Tauri v2, Zustand, Vite
- **Highlights / 亮点**: Serverless browser-to-browser P2P direct transfer, chunked large file streaming with memory overflow protection, IP Hash-based automatic LAN peer discovery, QR code quick pairing, and dual-mode deployment (Static Web / Cloudflare Pages + Tauri native desktop). / 基于 WebRTC / PeerJS 实现纯 P2P 端到端直连传输与免服务器中转；支持大文件切片流式传输防内存溢出与实时进度监控；内置基于 IP Hash 的局域网设备自发现与二维码扫码配对建房；提供纯静态 Web（Cloudflare Pages）与 Tauri 原生跨平台桌面端双端支持。

### 📁 [Rclone-Studio](https://github.com/code4lains/Rclone-Studio)
> **A modern, gorgeous, and dynamic Web & Desktop UI for Rclone.** / **一个为 Rclone 打造的现代、精美且充满动态反馈的桌面端/网页端管理工具。**
- **Stack / 技术栈**: Vue 3, TailwindCSS, Wails, Go
- **Highlights / 亮点**: Cross-platform (Desktop & Web) support, realtime monitoring dashboard, visual file browser, config wizard, and one-click remote mounting. / 提供原生桌面端与网页端双端支持，包含实时监控仪表盘、可视化文件浏览器、配置向导以及一键云盘挂载功能。

### 📄 [Serverless-Docs-Converter](https://github.com/code4lains/Serverless-Docs-Converter)
> **A pure frontend, zero-server document conversion tool.** / **一款纯前端的无服务端文档转换工具。**
- **Stack / 技术栈**: Vue 3, TypeScript, Vite, mammoth, docx, marked, SheetJS
- **Highlights / 亮点**: Completely serverless file conversion (DOCX, CSV, XLSX, Markdown) running entirely in the browser. Features optional S3-compatible storage integration for media, lazy-loaded modules for high performance, and built-in i18n support. / 完全在浏览器端运行的格式转换（DOCX, CSV, XLSX, Markdown），无需后端服务器。支持连接兼容 S3 的存储以处理内嵌媒体，通过模块懒加载优化性能，并内置国际化支持。

### ⚡ [FlareDrive-Pro](https://github.com/code4lains/FlareDrive-Pro) & ☁️ [R2-CloudDrive](https://github.com/code4lains/R2-CloudDrive)
> **Cloud storage solutions built on the edge.** / **基于边缘计算构建的云存储解决方案。**
- **Stack / 技术栈**: React / Vue 3, TypeScript, Cloudflare Pages & Workers, Cloudflare R2
- **Highlights / 亮点**: Highly localized and enhanced cloud drives running on Cloudflare's serverless infrastructure. `FlareDrive-Pro` features WebDAV compatibility, multi-threaded web uploads, and token validation. `R2-CloudDrive` provides multi-user permission management and directory-level access control. / 运行于 Cloudflare 无服务器基础设施上的网盘系统。`FlareDrive-Pro` 支持 WebDAV、网页端多线程上传及链接令牌验证；`R2-CloudDrive` 则提供了多用户权限管理和目录级访问控制。

### 🎮 [PC-Hardware-Ranker](https://github.com/code4lains/PC-Hardware-Ranker)
> **Performance benchmarking & value calculator for PC builders.** / **为 PC DIY 爱好者打造的性能天梯与性价比计算器。**
- **Stack / 技术栈**: React, React Router, i18next, Vite
- **Highlights / 亮点**: An interactive utility to help users make informed purchasing decisions. Includes a CPU/GPU bottleneck diagnosis tool, performance ranking ladder, and multi-language support. / 帮助用户做出明智购买决策的交互式工具，包含 CPU/GPU 瓶颈平衡诊断、性能天梯图以及多语言支持。
